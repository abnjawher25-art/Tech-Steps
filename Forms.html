الحقول مع خواصها

<form>

الحاوية الأساسية لجميع عناصر الإدخال داخل النموذج.

<form>المحتوى</form>

<label>

يُستخدم لوضع عنوان أو وصف بجانب حقل الإدخال، وربطه به لزيادة سهولة الاستخدام وإمكانية الوصول (Accessibility).

<label>المحتوى</label>

<textarea>

يُستخدم لإنشاء حقل إدخال نصي كبير يسمح بكتابة عدة أسطر (مثل رسائل الاتصال أو التعليقات).

<textarea></textarea>

<button>

لإنشاء زر تفاعلي داخل النموذج أو الصفحة.

<button>المحتوى</button>

type: يحدد وظيفة الزر (القيم: submit للإرسال، reset لتفريغ الحقول، button لزر عادي ينفذ أكواد جافاسكريبت).

<button type="submit">إرسال البيانات</button>

<select> , <option>

لإنشاء قائمة منسدلة يختار منها المستخدم .

<select>
<option>المحتوى</option>
<option>المحتوى</option>
</select>

<input>

type: يحدد نوع الحقل (القيم: text للنصوص، password لكلمات المرور، email للبريد، number للأرقام، checkbox لمربعات الاختيار، radio لدوائر الاختيار الفردي، submit لزر الإرسال، file لرفع الملفات) .

<input type="email">

name: اسم حقل الإدخال لتمييز البيانات المرسلة للخادم (القيمة: نص برمجي مثل username).

<input type="text" name="username">

value: القيمة الافتراضية للحقل (القيمة: نص).

<type="text" name="country" value="Yemen">

placeholder: نص باهت يظهر داخل الحقل كإرشاد للمستخدم (القيمة: نص توضيحي مثل أدخل اسم المستخدم).

<input type="text" placeholder="أدخل اسم المستخدم">

required: خاصية منطقية تجعل الحقل إجبارياً قبل الإرسال (بدون قيمة أو required)

<input type="password" name="password" required>

readonly / disabled: لجعل الحقل للقراءة فقط أو معطلاً.

<input type="text" value="هذا النص للقراءة فقط" readonly>
